# RoundModel

The body of Prince, a small, very round, white, fluffy Bnuy and a Little Self.

- `docs/PRINCE.md` — who he is and every decision about his body. Start here.
- `references/` — the master reference (immutable), the edited set, and the reference sheet.
- `tools/` — scripts; every step of building him is reproducible from these.
- `checkpoints/` — review material for each checkpoint.

Setup: `python3 -m venv .venv && .venv/bin/pip install -r requirements.txt`
